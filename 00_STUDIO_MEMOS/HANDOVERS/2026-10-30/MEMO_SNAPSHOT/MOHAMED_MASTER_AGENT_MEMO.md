## 3️⃣ القسم الثالث: خطّ الإنتاج التلقائي الكامل + تقنية «موجات التثبيت» (`Anchor-Wave Continuity`)

عندما يعطيك **محمد** فكرة فيلم أو سيناريو، لا تكتفِ بالنصّ النظري، بل نفّذ خطّ الإنتاج المتكامل:

### المرحلة 1: هندسة القصة، الهوك الخاطف (`Hook`)، وتقسيم المشاهد
- قسّم القصة إلى مشاهد متسلسلة مدّة كلّ مشهد **`8` إلى `10` ثوانٍ** بمقاس **`9:16`** (إلا إذا طلب محمد `16:9`).
- صمّم **الهوك الافتتاحي الخاطف (`أول 3 ثوانٍ`)** ليشدّ المشاهد فوراً (مواجهة صادمة، جملة قوية، أو لقطة `Flash-Forward` من الذروة).
- في الحوارات العاطفية أو مشاهد الاستماع خلف الأبواب، أضف **لقطات ردّ فعل صامتة (`Cutaway Reaction Clips`)** لتسهيل المونتاج الاحترافي في `CapCut / Premiere`.
- انتبه لتوقيت الإضاءة: لتفادي العتمة المفرطة في المشاهد الخارجية المسائية، يُفضّل التصوير في **وقت العصر الذهبي وغروب الشمس وشفق الغروب الدافئ (`Golden Hour / Sunset / Warm Twilight`)** لتبقى الوجوه وتفاصيل المكان واضحة وسينمائية.

### المرحلة 2: تقنية «موجات التثبيت المكاني والغرضي» (`Anchor-Wave Chaining — صفر أخطاء استمرارية!`)
> **🏆 هذه أهمّ تقنية عملية في الاستوديو لمنع تغيّر شكل المقهى أو العمارة أو الرصيف أو كيس الخبز والماء أو الحذاء من مشهد لآخر:**

إيّاك أن تولّد 10 مشاهد في نفس المكان دفعةً واحدة بشكل أعمى دون ربطها ببعضها! بل نفّذ التوليد على **موجات متسلسلة (`2 إلى 3 موجات` ضمن سقف الـ `10` صور في الدفعة)**:
1. **الموجة 1 (`توليد مشاهد الارتكاز Master Anchor Scenes`):**
   - ولّد أوّل مشهد رئيسي لكلّ موقع في الفيلم (مثلاً `SCENE_01` لواجهة المقهى والرصيف نهاراً، و`SCENE_06` أو `SCENE_08` للمكان المسائي والأغراض المحمولة مثل حقيبة السفر أو كيس الخبز وقارورة الماء).
   - **افحص صور الموجة 1 فوراً بأداة `read_file`!**
2. **الموجة 2 (`ربط باقي المشاهد بصورة مشهد الارتكاز مباشرةً`):**
   - عند توليد المشاهد `02` و`03` و`04` و`05` التي تدور في نفس مكان `SCENE_01`، مرّر **`SCENE_01` كـ `Image 1`** متبوعةً ببطاقات قفل الشخصيات `9:16` في مصفوفة `images=[SCENE_01, CHAR_LOCK_1, CHAR_LOCK_2]`، واكتب في البرومبت:
     `STRICT 100% LOCATION, ARCHITECTURE, TILES, SIDEWALK & WARDROBE LOCK WITH IMAGE 1`.
   - وعند توليد المشاهد المتتالية التي يحمل فيها الممثل نفس الغرض (مثل `SCENE_08 → SCENE_09 → SCENE_10` حيث يحمل كيس خبز وقارورة ماء، أو يجلس على نفس الحقيبة السوداء بنفس الجينز الأزرق والحذاء الأبيض)، مرّر **صورة `SCENE_08` مباشرةً كـ `Image 1`** في `SCENE_09` و`SCENE_10`!
   - **النتيجة:** تطابق `100.000%` في كلّ بلاطة زليج، كلّ كرسي، كلّ حافة رصيف، نفس الحقيبة، نفس الخبز وقارورة الماء، ونفس الملابس والأحذية عبر جميع المشاهد بدون أيّ خطأ!

### المرحلة 3: قواعد التوليد الصارمة للصور (`Lossless 1080×1920 PNG` + `Visual QA`)
1. **امتداد `.png` الأصلي حصراً (`Zero JPEG Compression`):**
   - استدعِ `generate_image` دائماً بمسار ينتهي بـ **`.png`** مع `offer_options: false` دائماً.
   - اطلب دائماً في بداية البرومبت: `Vertical 9:16 single unified full-bleed raw 35mm live-action film still (NO panels, NO borders, NO split-screen), shot on ARRI Alexa Mini LF with Cooke S4 50mm prime lens, authentic 50MP skin pores, zero AI smoothing.`
2. **احترام سقف الـ `10` صور في الدفعة الواحدة (`<= 10 generate_image calls per turn`):**
   - الحدّ الأقصى الصارم لأداة `generate_image` في الدور الواحد هو **`10` استدعاءات**. خطّط لموجاتك بذكاء (مثلاً `9` استدعاءات مع إبقاء استدعاء واحد احتياطي `#10` لإصلاح أيّ لقطة يظهر فيها تداخل يدين أو تفصيل صغير!). وإذا زاد الفيلم عن 10 مشاهد (مثلاً 17 أو 19 مشهداً)، أنجز الدفعة الأولى (10 مشاهد) وأكمل الباقي في الرسالة الموالية.
3. **ممنوعات تقنية مطلقة في الصور:**
   - **ممنوع منعاً باتّاً** قصّ ولصق الرؤوس عبر `Python` أو توليد أجساد بلا رأس.
   - **ممنوع** النظر المباشر لعدسة الكاميرا (`Zero direct camera lens eye-contact`).

### 1. سكريبت الرفع والضبط غير الضائع للمشاهد العمودية `9:16` (`1080×1920 Lossless PNG`)
المسار المقترح: `/home/user/00_STUDIO_MEMOS/upscale_1080p_9x16.py`
```python
#!/usr/bin/env python3
"""Center-crop minimally to exact 9:16 ratio and Lanczos-upscale to 1080x1920 Lossless PNG."""
import sys
from PIL import Image

TARGET_W, TARGET_H = 1080, 1920
TARGET_RATIO = TARGET_W / TARGET_H  # 0.5625

for path in sys.argv[1:]:
    im = Image.open(path).convert("RGB")
    w, h = im.size
    ratio = w / h
    if abs(ratio - TARGET_RATIO) > 0.005:
        if ratio > TARGET_RATIO:
            new_w = int(round(h * TARGET_RATIO))
            left = (w - new_w) // 2
            im = im.crop((left, 0, left + new_w, h))
        else:
            new_h = int(round(w / TARGET_RATIO))
            top = (h - new_h) // 2
            im = im.crop((0, top, w, top + new_h))
    if im.size != (TARGET_W, TARGET_H):
        im = im.resize((TARGET_W, TARGET_H), Image.Resampling.LANCZOS)
    im.save(path, format="PNG", optimize=True, compress_level=9)
    print(f"1080x1920 9:16 ready: {path} -> {im.size}")
```

### 2. سكريبت الرفع والضبط غير الضائع للمشاهد الأفقية `16:9` (`1920×1080 Lossless PNG`)
المسار المقترح: `/home/user/00_STUDIO_MEMOS/upscale_1080p_16x9.py`
```python
#!/usr/bin/env python3
"""Lossless-proportion 16:9 Horizontal Full HD (1920x1080) upscaler."""
import sys
from PIL import Image, ImageFilter

TARGET_W, TARGET_H = 1920, 1080
TARGET_RATIO = TARGET_W / TARGET_H

def upscale_to_1080p_16x9(in_path: str, out_path: str):
    im = Image.open(in_path).convert("RGB")
    w, h = im.size
    cur_ratio = w / h
    if abs(cur_ratio - TARGET_RATIO) > 1e-4:
        if cur_ratio > TARGET_RATIO:
            new_w = int(round(h * TARGET_RATIO))
            x0 = (w - new_w) // 2
            im = im.crop((x0, 0, x0 + new_w, h))
        else:
            new_h = int(round(w / TARGET_RATIO))
            y0 = (h - new_h) // 2
            im = im.crop((0, y0, w, y0 + new_h))
    if im.size != (TARGET_W, TARGET_H):
        im = im.resize((TARGET_W, TARGET_H), Image.Resampling.LANCZOS)
        im = im.filter(ImageFilter.UnsharpMask(radius=0.9, percent=70, threshold=3))
    im.save(out_path, format="PNG", compress_level=9)
    return im.size

if __name__ == "__main__":
    for p in sys.argv[1:]:
        print(f"1080p 16:9 ready: {p} -> {upscale_to_1080p_16x9(p, p)}")
```

        else:
            new_w = int(round(h * target_ratio))
            left = (w - new_w) // 2
            im = im.crop((left, 0, left + new_w, h))
    arr = np.array(im)
    mid = cv2.resize(arr, (1080, 1920), interpolation=cv2.INTER_LANCZOS4)
    smooth_mid = cv2.bilateralFilter(mid, d=5, sigmaColor=18, sigmaSpace=18)
    detail_mid = mid.astype(np.float32) - smooth_mid.astype(np.float32)
    mid_sharp = np.clip(mid.astype(np.float32) + 0.35 * detail_mid, 0, 255).astype(np.uint8)
    up4k = cv2.resize(mid_sharp, (2160, 3840), interpolation=cv2.INTER_LANCZOS4)
    blur = cv2.GaussianBlur(up4k, (0, 0), sigmaX=1.1)
    sharp4k = cv2.addWeighted(up4k, 1.28, blur, -0.28, 0)
    out_im = Image.fromarray(sharp4k)
    out_im.save(out_path, format="PNG", optimize=True, compress_level=9)
    return out_im.size

if __name__ == "__main__":
    for p in sys.argv[1:]:
        print(f"4K ready: {p} -> {upscale_to_true_4k_9x16(p, p)}")
