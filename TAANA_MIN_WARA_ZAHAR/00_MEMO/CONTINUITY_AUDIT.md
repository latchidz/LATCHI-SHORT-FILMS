## 1. الخلاصة التنفيذية

الحزمة السابقة (5 مراجع + 7 مشاهد) كانت **سليمة تقنياً** (9:16، وجوه ثابتة) لكنها **لا تحقق المخطط المكاني الجديد** ولذلك لا تصلح كسلسلة متصلة:

| المشكلة | الأثر | القرار |
|---|---|---|
| مرجع المقهى القديم فاتح جداً، شبه فارغ، أرضية رمادية ونوافذ طويلة | يبدو كاستوديو تصوير لا كمقهى جزائري دافئ | **إعادة توليد المرجع** ✅ |
| الباب في الخلف/يسار الكادر بشكل غير محدد | اتجاه دخول أمين غير مقفل | **تحديد: الباب في العمق إلى اليسار** ✅ |
| طاولة المسن «يمين الكادر» | يخالف المخطط الجديد (قرب النافذة/اليسار) | **تحديث: قرب النافذة** ✅ |
| فؤاد بقميص رمادي فحمي | المذكرة تعتمد **أزرق داكن/رمادي مزرق + بنطال بيج** | **إعادة توليد REF_03** ✅ |
| غياب زاوية عكسية للمكان | لا يمكن قفل هندسة المكان | **إنشاء REF_06** ✅ |
| غياب مرجع طاولة الأصدقاء (قبل/بعد أمين) | يسمح بتبدّل عدد الكراسي والكؤوس | **إنشاء REF_07 + REF_08** ✅ |

**النتيجة:** المراجع الخمسة القديمة + المشاهد السبعة **مُستبدلة/مُلغاة** ولا تُستخدم كمرجع للمشهد التالي (قاعدة §11.6).

## 3. المخطط المكاني المعتمد (نهائي — لا يُغيَّر)

```
        [ البار + آلة الإسبريسو — الجدار الخلفي ]
                              |
   [الباب]                    |
   (عمق يسار)                 |
        \                     |
  [نوافذ الجدار الأيسر]   ┌─────────────┐
        ☀ ضوء           │  طاولة القصة │
                        │   (وسط)     │
   [طاولة المسن]        │  فؤاد ▲     │
   (قرب النافذة)        │  رضا    [كرسي أمين ← يسار]
                        └─────────────┘
                              ▲
                    الكاميرا (من جهة الباب)
```

| العنصر | الموضع الثابت |
|---|---|
| **الباب** | العمق — إلى **اليسار** |
| **النوافذ** | الجدار **الأيسر** — مصدر الضوء |
| **البار + آلة القهوة** | الجدار **الخلفي** |
| **طاولة القصة** | **وسط** المقهى، على مسافة واضحة من البار |
| **كرسي رضا** | الجانب **الأيمن** من الطاولة |
| **كرسي فؤاد** | الجانب **المقابل/الخلفي** — قريب من جهة البار |
| **كرسي أمين** | الجانب **الأيسر** — **فارغ قبل وصوله** |
| **طاولة المسن** | منفصلة — **قرب النافذة** |
| **اتجاه الكاميرا** | من جهة الباب نحو الطاولة والبار |
