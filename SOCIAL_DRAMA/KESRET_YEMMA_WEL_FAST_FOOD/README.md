# 🎬 «كَسْرَة يَمَّا وَالفَاسْت فُود» (`KESRET YEMMA WEL FAST FOOD`) — النسخة التنظيمية الكاملة النهائية

- **التصنيف:** دراما اجتماعية جزائرية واقعية (`SOCIAL_DRAMA`)
- **التصوير والدقة:** أفقي `16:9` · `Full HD (1920 × 1080)` · واقعية سينمائية خام `35mm Live-Action`
- **تنظيم الملفات:**
  - **`00_MEMO/`** — الستوريبورد التنفيذي + السيناريو المنظّم للتسجيل الصوتي.
  - **`01_REFERENCES/`** — المراجع الـ 4 المقفولة بدقة `1920×1080` (`الخالة يمينة`، `ياسين`، `رمزي`، `كيس الكسرة`).
  - **`02_SCENES/`** — **كل مشهد في مجلده الخاص المستقل** (`SCENE_01/` إلى `SCENE_12/` وبداخله `S12A` لاعتذار أمين الكامل + `S12B` لمسامحة الأم وعناقها).
  - **`03_FLOW_PROMPTS/`** — **جميع البرومبتات مجموعة معاً في مجلد واحد** (`00_ALL_PROMPTS_TOGETHER.md` + `PROMPT_01` إلى `PROMPT_12B`) ومضبوطة بالثانية على مدة ملفات صوت أمين المسجَّلة (مع توفير الخيار `A` الناطق والخيار `B` لتحريك الشفاه الصامت في مشاهد أمين `04` و`07` و`12A`).
  - **`04_AUDIO_AMIN/`** — النسخ الـ 5 المعدّلة لصوت أمين (الكاملة + المقسّمة الجاهزة للمونتاج لكل مشهد `SCENE_04`، `SCENE_07`، `SCENE_12A`).
