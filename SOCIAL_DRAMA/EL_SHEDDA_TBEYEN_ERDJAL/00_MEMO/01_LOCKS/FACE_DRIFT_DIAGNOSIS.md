## ⚠️ الجواب الأول — بصراحة

**الفرق ماشي في النموذج. الفرق في جودة المرجع اللي نعطيهولو.**

| | الشخصيات اللي "تقعد كيفها" | أمين ويوسف |
|---|---|---|
| **المرجع** | ورقة كاملة **1672×941** فيها 4–6 أوضاع | قص **350×444** و **512×480** |

| **النتيجة** | ثبات مقبول | **تغيّر في الملامح** |

النموذج يمشي بنفس الخوارزمية. المشكلة: **المرجع صغير ومضغوط**، فيعمّر الفراغات بالتخمين.

## 🔬 التشخيص التقني — 5 أسباب حقيقية

### 1️⃣ دقّة المرجع (أكبر سبب)
```
REF_AMIN_FACE.png     = 350 × 444     ← الوجه ياخذ ~250 بكسل
REF_YOUSSEF_FACE.png  = 512 × 480
REF_MARYAM_SHEET.png  = 768 × 1376    ← ورقة كاملة، الوجه أكبر
```
المرجع كل ما كان أصغر، النموذج **يخمّن** أكثر. التخمين = وجه مختلف.

### 2️⃣ عدد المراجع (2 مقابل 3)
```
مريم  ← مرجع واحد كبير         → ثبات عالي
أمين  ← مرجعين صغار + مكان     → 3 مراجع، ثلثهم مشغول بالمكان
```
`generate_image` عندو **3 مراجع كحد أقصى**. إذا واحد منهم المكان، يبقى **2 بس** للوجه — والانتباه يتوزّع.

### 3️⃣ الوجه صغير في الكادر
في `S1a` أمين يجلس على بعد 4 متر، ووجهو ~120 بكسل من أصل 1376.
النموذج ما عندوش تفاصيل كافية → يخترع. **لهذا S2b (youssef close-up) طلع أدق من S2a.**

### 4️⃣ الملابس مختلفة عن الورقة
ورقة أمين: **قميص أزرق فاتح + بنطال رمادي**.
المشهد: **قميص رمادي فحمي**.
النموذج يربط "التغيير في اللباس" بـ"تغيير في الهوية" — فيبدا يعدّل الوجه.

### 5️⃣ صيغة البرومبت
لما نكتب:
```
THE FATHER (reference 2): the man of the sheet, identity locked — same face...
```
النموذج يفهم **"رجل يشبه الورقة"**، ماشي **"نفس الشخص بالضبط"**.

الصيغة الصحيحة:
```
USE THE EXACT MAN from reference 2. This is the same person, not a lookalike.
Copy his face pixel for pixel.
```

## 🛠️ الحل — 6 خطوات

### ✅ 1. مرجع وجه مكبّر ومحسّن (تمّ)
```
IDENTITY_REFS/AMIN/REF_AMIN_ID.png        675 × 1030   ← جديد
IDENTITY_REFS/YOUSSEF/REF_YOUSSEF_ID.png  756 × 720    ← جديد
```
قصّ ضيّق + تكبير 2.2× + unsharp mask. الوجه ولّى ياخذ الكادر كامل.

### ✅ 2. بروتوكول المراجع — 2 + 1
```
[ REF_ME_ID ]  +  [ ENV ]        ← مشهد فيه شخصية وحدة
[ REF_ME_ID ]  +  [ REF_OTHER ]  ← مشهد فيه جوج فقط (بلا مكان)
```
⛔ **ما نزيدش مرجع ثالث** إلا إذا كان ضروري.

### ✅ 3. ابدأ بالشخصية، ماشي بالمكان
```
المرجع 1 = الوجه   (ديما الأول)
المرجع 2 = الشخصية الثانية
المرجع 3 = المكان  (الأخير)
```
الترتيب يهم — النموذج يعطي وزن أكبر للأول.

### ✅ 4. صيغة البرومبت الجديدة
```
❌ THE FATHER (reference 2): the man of the sheet...
✅ USE THE EXACT MAN IN REFERENCE 1. Same real person, not a lookalike.
   Copy his face exactly: face shape, brows, eyes, nose with the small faint
   mark on the bridge, lips, ears, beard length, hair cut and skin texture.
   Only his CLOTHING and EXPRESSION may change.
```

### ✅ 5. لقطة قريبة أو متوسطة — ماشي واسعة
| المسافة | ثبات الوجه |
|---|---|
| Wide (كامل الجسم في كادر) | ⚠️ ضعيف |
| **Medium (نص الجسم)** | ✅ **الأفضل** |
| **Close-up** | ✅✅ **الأقوى** |
| Extreme wide | ❌ ما ينفعش |

**لهذا:** كل مشهد فيه شخصية مهمة = **لقطة متوسطة على الأقل**.

### ✅ 6. اللباس يتبع الورقة
إذا حبّينا نبدّل اللباس، نكتب صراحة:
```
He wears a different outfit from the sheet: ONE charcoal-grey shirt.
His FACE, HAIR, BEARD and BODY are unchanged from the reference.
```
بلا هذي الجملة، النموذج يعتبر كلشي تبدّل.
