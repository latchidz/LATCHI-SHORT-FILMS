### 🔄 سير العمل
1. توليد صور المشاهد بالذكاء الاصطناعي (ثبات الوجوه/الملابس/الهندسة عبر المراجع).
2. رفع الصور الثلاث + البرومبت إلى **Google Flow** لإنتاج فيديو 10 ثوانٍ لكل مشهد.
3. تجميع المقاطع بترتيب SC01→SC27 حسب دليل التصدير.
