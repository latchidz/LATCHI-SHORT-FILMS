كل مشروع **يحمل أرشيفه الكامل داخله** — لا مذكرة في مكان آخر:

| داخل كل مجلد مشروع | المحتوى |
|---|---|
| `README.md` | بطاقة المشروع: القصة، الشخصيات، الحالة، القواعد |
| `00_MEMO/` | **المذكرة + السيناريو + الحوار** |
| `01_REFERENCES/` | مراجع الشخصيات والأماكن |
| `02_SCENES/` | اللقطات النهائية |
| `03_FLOW_PROMPTS/` (أو `04_...`) | **برومبتات التحريك** لكل لقطة |
