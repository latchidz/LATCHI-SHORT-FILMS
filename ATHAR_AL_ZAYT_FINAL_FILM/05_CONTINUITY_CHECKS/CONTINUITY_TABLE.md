# جدول فحص الاستمرارية — «آثار الزيت»
**القاعدة:** أي صورة تخفق في أي بند ← تُعاد **قبل** استخدامها لبرومبت الفيديو.

## أعمدة الفحص (لكل مشهد)

|---|---|
| F1 | الصيغة 16:9 أفقية؟ (لا عمودي ولا مربع) |
| F2 | وجه الشخصية مطابق للمرجع المعتمد؟ |
| F3 | الملابس ثابتة (سترة الحاج الخضراء/بدلة أمين+الأحمر/بنية ياسين/فستان الأم…)؟ |
| F4 | المكان مطابق لمرجع الموقع (اتجاه الأبواب/الأثاث)؟ |
| F5 | المكتب + الصندوق (يسار المكتب) + الشاشة (حائط يمين المكتب) ثابتة؟ |
| F6 | الحركة/الوضعية منطقية ومتصلة بالمشهد السابق؟ |
| F7 | الحوار جزائري طبيعي ومتحدث واحد؟ |
| F8 | المدة 10 ثوانٍ بالضبط في برومبت Flow؟ |
| F9 | آخر إطار قابل للوصل ببداية المشهد التالي؟ |
